Upload a document

A Word file, a PDF or a text file with the numbers written in it. I read the numbers out and put them in the boxes for you to check.

What the document needs:

  • the name of each group
  • its number, either on the same line or the line below

Like this: "Most buyers: 233". Tables and paragraphs both work.
